## Core methods and application policy

Public [Blake](https://github.com/docxology/blake) owns reusable corpus custody,
portable schemas, matching, statistics, intervals, composition, hierarchy and
review methods. The applications own their vocabularies, contextual decisions,
source groupings, domain models and manuscripts. The sibling application is
independent. Generic manuscript hydration, numbering and native writers belong
to [docxology/template](https://github.com/docxology/template).

Federalism delegates corpus mathematics and custody to Blake. The unused
statistics re-export and bootstrap ReportLab body renderer have been removed
from active source. Use the installed `blakean render-manuscript` command and
its pinned-template worker. [The maintenance qualification](../research/methods-retirement-20261103.json)
accounts for the retired tests and changed producer closure; exact preimages
remain in [historical custody](../research/history/documentation-maintenance-20261103-preimage/manifest.json).

## Installed-source and coverage checks

A release wheel and an application Git pin can contain different captured
build metadata despite sharing a version label. This maintenance checks the
applications against their exact selected Git source and declared force-includes;
a comparison to a later release wheel is not interchangeable. The initial
comparison and a diagnostic that read the core checkout are preserved as
unqualified attempts, not evidence of a reproduced SDK defect. Both normal
installed source/resource sets pass the corrected exact-pin check.

After normal installation, use explicit --no-sync commands. Coverage retains
all raw child-process counters, including intentionally changed fixture sources,
while qualification reports select the complete current installed package and
checkout tools roots. Changed fixtures remain separate source identities.
